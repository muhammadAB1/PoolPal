# Pool Test-Strip Chart — Labels Above Rows

The test name for each chemical is placed above its color row rather than in a left-hand label column.

Use `pool_chart_labels_above_editable.svg` as the primary editable master.

Every color swatch is an independent SVG rectangle with its own fill and unique object ID. All text remains live Poppins text. The source photograph is not embedded.

Adobe Express can import the SVG and expose its detected colors for recoloring. For guaranteed one-square-at-a-time editing, open the SVG in Illustrator, Figma, or Inkscape, select the rectangle by ID, change the fill, save, and re-import.

The package includes transparent PNG exports, iOS and Android previews, CSV and JSON color inventories, and measurement specifications.
