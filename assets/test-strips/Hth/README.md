# HTH 6-Way Mobile Color Chart

Use `hth_6way_mobile_editable.svg` as the editable master.

Every color swatch is an independent SVG rectangle with a unique ID and fill value. The chart uses uniform square swatches, labels above each row, and generous vertical spacing for mobile readability.

The package includes:
- Editable SVG master
- Transparent PNG exports at 1×, 2×, and 3×
- iOS and Android previews
- CSV and JSON HEX/RGB color inventories
- Measurement and developer handoff specifications

Adobe Express can import the SVG and expose detected colors for recoloring. Illustrator, Figma, or Inkscape provide more reliable one-square-at-a-time selection.
