# Pool Test-Strip Chart with A–E Markers

Use `pool_chart_ae_markers_mobile_editable.svg` as the editable master.

Every swatch is an independent SVG rectangle with a unique object ID and fill. The original A–E markers and numerical values remain separate editable text elements below their corresponding squares.

The package includes:
- Editable SVG master
- Transparent PNG exports at 1×, 2×, and 3×
- iOS and Android previews
- CSV and JSON HEX/RGB color inventories
- Measurement and developer handoff specification

Adobe Express can import the SVG and expose detected colors for recoloring. Illustrator, Figma, or Inkscape provide more reliable one-square-at-a-time selection.
