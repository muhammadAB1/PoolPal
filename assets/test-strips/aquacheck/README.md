# AquaChek 7-in-1 Mobile Color Chart

Use `aquachek_7in1_mobile_editable.svg` as the editable master.

Every swatch is a separate SVG rectangle with an independent fill and unique object ID. The combined Total Chlorine / Total Bromine row retains separate TC and TB labels and values. Source classifications and range indicators are reconstructed as separate editable vector and text elements.

The package includes:
- Editable SVG master
- Transparent PNG exports at 1×, 2×, and 3×
- iOS and Android previews
- CSV and JSON HEX/RGB color inventories
- Measurement and developer handoff specification

Adobe Express can import the SVG and expose detected colors for recoloring. Illustrator, Figma, or Inkscape provide more reliable one-square-at-a-time selection.
