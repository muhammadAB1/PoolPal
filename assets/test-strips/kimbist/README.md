# Pool Test Strip Chart V3

Use the editable SVG as the primary master. Every swatch and green status band is an independent vector object.

Adobe Express can import and recolor SVG graphics, but may expose detected colors rather than fully separate layers. For guaranteed one-square editing, open the SVG in Illustrator, Figma, or Inkscape, select the rectangle by ID, change its fill, save, and re-import.

The SVG is responsive and should be displayed proportionally at 358 px wide on the iOS reference artboard or 328 px wide on Android.
