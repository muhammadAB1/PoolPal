# Pool Test Strip Chart V4 — Badge Removed

The red “150 STRIPS” promotional badge has been completely omitted from the reconstructed chart.

Use `pool_test_strip_chart_v4_editable_no_badge.svg` as the editable master.

Every swatch is a separate SVG rectangle with its own object ID and fill. The ideal-range brackets are separate vector paths, and all typography remains live Poppins text.

Adobe Express can import the SVG and expose its detected colors for recoloring. Depending on the editor version, individual rectangles may be grouped as one graphic. For guaranteed one-square-at-a-time editing, open the SVG in Illustrator, Figma, or Inkscape, change the selected rectangle’s fill, save, and re-import.

The package includes:
- Editable SVG
- Transparent PNG at 1×, 2×, and 3×
- iOS and Android white-background previews
- CSV and JSON color inventories
- Measurement specification
